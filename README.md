# Referenzbild-Analysator

Eine Web-App für die Ölmalerei. Sie läuft komplett im Browser, auch offline. Fotos werden nur auf dem Gerät verarbeitet und nirgends hochgeladen.

- Graustufen, Tonwerte (2–10 Stufen), Temperatur und mischbare Farben
- Farbflächen mit Mutterfarben, Varianten und Variationsfeld
- Mischrezepte aus Titanweiß, Ultramarinblau, Burnt Umber, Pyrrolrot und Primärgelb (Cobra)
- Raster passend zum Leinwandformat, Spiegeln, Augen zusammenkneifen

## Auf dem Handy installieren

Die Seite öffnen und auf den Home-Bildschirm legen:
- iPhone (Safari): Teilen → Zum Home-Bildschirm
- Android (Chrome): Menü ⋮ → App installieren

## Neue Version veröffentlichen

Dateien ersetzen und in `sw.js` die Versionsnummer (`rba-v1` → `rba-v2`) erhöhen, damit installierte Apps die neue Fassung laden.
